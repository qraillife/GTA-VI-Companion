# VI Companion

An unofficial, mobile-friendly Grand Theft Auto VI countdown and launch information app.

## Features

- Live countdown to **19 November 2026 at midnight**, calculated separately for each selected timezone
- Timezone selection (browser-native dropdown) with major regions listed first, and automatic device timezone detection
- Game information, characters, setting, platforms and performance details
- Links to official Rockstar trailers, screenshots and Newswire articles
- Pre-load information, official store links and launch checklist
- Checklist progress and timezone preference saved locally on your device
- Installable progressive web app (PWA), with icons and offline access to app pages
- Responsive design for phones, tablets and desktop computers

## Publish with GitHub Pages

1. Create a **public GitHub repository** (for example `vi-companion`).
2. Upload **all files and the `icons` folder** from this project. The `index.html` file must be in the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Select **main**, choose **/(root)**, then **Save**.
6. Open the URL shown by GitHub Pages when deployment finishes.

## Install on iPhone

Open the GitHub Pages URL in Safari, tap **Share**, then **Add to Home Screen**.

## Install on Android or desktop

Open the GitHub Pages URL in a supported browser and select **Install app** or **Add to Home Screen** from the browser menu.

## Important notes

- The countdown follows Rockstar's announced **midnight local-time** release in each region. The relevant PlayStation/Xbox store or account region may differ from the chosen display region.
- Live countdown is calculated using your device's time and timezone database. If the device clock is wrong, the countdown can be wrong.
- News headlines included in the app were checked on **15 November 2026**; the app links to Rockstar Newswire for newer information. They are not automatically fetched.
- Offline access requires opening the app online at least once. Links to external media require internet.
- This is a **fan-made project** and is not affiliated with Rockstar Games or Take-Two Interactive. All related trademarks belong to their owners.

## Media inside the app

The media tab has a playable trailer viewer and screenshot gallery; neither requires navigating to an outside page. Trailer streams, image files and official Rockstar logo are loaded from online sources, so an internet connection is required to display those assets. The countdown and locally cached app shell work offline. The screenshots and video footage are owned by Rockstar Games / Take-Two.
